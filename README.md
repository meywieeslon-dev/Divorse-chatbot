# Помощник при разводе

Чат-бот, который отвечает на общие вопросы про развод в России: как подать на развод, что будет с детьми, как делится имущество и т.д.

Бот не заменяет юриста — он даёт только общую справочную информацию.

## Из чего состоит проект

- `app.py` — экран, который видит пользователь (сделан на Streamlit)
- `server.py` — часть, которая принимает вопросы и передаёт их дальше (на FastAPI)
- `graph.py` — логика диалога: какие вопросы задавать и в каком порядке
- `guardrails.py` — проверка, что вопросы и ответы касаются именно темы развода
- `Dockerfile` и `Dockerfile.streamlit` — инструкции для запуска проекта в Docker
- `docker-compose.yml` — запускает обе части проекта (сервер и экран) одновременно

## Как запустить

1. Создать файл `.env` в корне проекта со строкой:
GIGACHAT_AUTH_KEY= КЛЮЧ
2. Выполнить команду:
docker compose up --build -d 
3. Открыть в браузере: `http://localhost:8501`
